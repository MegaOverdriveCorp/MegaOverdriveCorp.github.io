Product line / real repositories
super-architectJavaScript

Super Architect

Draw cloud architectures and database schemas in your browser. One HTML file, no server, no install, no account, Claude built in.

  • Official Azure and Microsoft Fabric icons, plus dbt, dlt and Snowflake. Groups, labelled data flows, notes, legend, auto layout.
  • Templates: Fabric medallion, real-time intelligence, mirroring, CI/CD, Databricks medallion and MLOps, Azure landing zone, hub-spoke, AKS baseline, RAG with Azure OpenAI, Lambda, Kappa.
  • Data models with keys and crow's foot relationships. Kimball star schema, fact constellation, SCD type 2, Data Vault, 3NF. Exports SQL DDL for Fabric Warehouse and Synapse, and Mermaid ER diagrams.
  • Ask Claude for a diagram in one sentence, with your own API key or as a Claude artifact through the bundled skill. The ralphitecture skill turns a repo, a Fabric workspace export, dbt, Terraform or Bicep into an importable model.
  • PNG, SVG and JSON export. Three styles, one of them 16-bit. Dutch, English and Spanish. Works offline.

new-york-pizza-kortingPython

New York Pizza Korting

Find the discount codes that apply to a New York Pizza order. Fill a basket, run the search, get the best code or combination of codes.

  • A local proxy in front of the public web shop adds a Get JSON basket button to every page and a Run now button that searches with live progress.
  • Tries the numeric codes in a range (100 to 775 by default), reports what each one takes off, and stacks the codes that apply to find the best combination.
  • Runs in a separate shop session, so your basket is untouched. Never places an order, never touches payment details, refuses checkout unless you say so.
  • Python 3.12 and uv. CLI (korting), importable client library, tests without network access, ruff for lint and format.
  • Replaces the original PHP script, which is kept in legacy/ for reference only.

Principles
  • One file
    Ship a single file when you can

    Super Architect is one HTML page with icons and logo inline, built from src/ by a Python script with no packages. This site is one HTML file too.

  • Local
    No server, no account

    Diagrams save in your browser. The pizza tool runs a proxy on localhost only and refuses to place orders unless you ask.

  • Claude
    Claude built in, keys stay yours

    Super Architect talks to api.anthropic.com with your own key, never written into the file, or runs as a Claude artifact through its bundled skill.

  • Tooling
    uv, pytest, ruff

    The Python side uses uv for environments, pytest with captured HTML fixtures so tests need no network, and ruff for lint and format.

  • Style
    Three styles, one of them 16-bit

    Zakelijk, Minimaal and the retro pixel style you are looking at right now, which is also the house style of this page.
